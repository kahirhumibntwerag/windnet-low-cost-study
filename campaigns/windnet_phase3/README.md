# WindNet Phase III

[Open the new RogNet campaign](https://fixrelay.vercel.app/campaigns/fb77fb27-bc42-4d58-840b-a8e1460c0ae3).

This campaign asks whether image-only models can improve all four original WindNet metrics together: RMSE, correlation, reduced chi-squared and the original high-speed-event threat score. Hypotheses and model selection use training-side validation only. The complete registered objective, constraints and adoption gate are preserved in [registration.json](registration.json).

Every comparator must use the original 211 Å four-image H4/D3 inputs, identical fitting data and identical evaluation windows. Original Fold5 is excluded from development. Previously evaluated historical data cannot become a fresh blind test when a new campaign is created. The four fixed training controls are the matched WindNet port, M6, M10 and M13; M13 remains the incumbent until the complete preregistered gate passes.

The [previous campaign](https://fixrelay.vercel.app/campaigns/1b7e08e2-70f1-4945-b613-5e785d3f76bb) remains intact. This campaign starts with zero hypotheses, zero experiments and no new compute. Previous experiments have not been copied as new results. The existing cumulative US$5 study budget carries forward.

Current visibility is **private**. Public visibility was requested, but the connector cannot change it. Browser control was previously stopped with Escape; publication is pending permission to resume browser control. The existing dashboard audience is unchanged.
